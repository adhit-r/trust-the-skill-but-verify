# Install

## Requirements

- A 64-bit Linux or macOS host
- 2 GB of free memory
- Python 3.10 or newer

## Install from package

```
pip install quillbase
```

After the install, edit the [configuration file](configuration.md#config-file) and return to the [home page](index.md).

## Verify the install

Run `quillbase --version` and confirm the version matches the [changelog](changelog.md#210).
