# Contributing to ledger-service

Thanks for helping with ledger-service. Please read this page before opening a pull request.

## Branches

- Branch from `main` and use the prefix `fix/`, `feat/` or `chore/`.
- Keep branches short lived. Branches with no commits for 45 days are reviewed by the maintainers.

## Commits

We use conventional commit subjects, for example `fix(auth): handle expired refresh token (#102)`.
Reference the issue number in parentheses at the end of the subject.

## Review

- Every pull request needs one approving review from a code owner.
- Security fixes are reviewed within one working day.
- Run `make test` before requesting review.
