# Access Control Policy

Owner: Head of IT Operations
Version: 3.2

## 1. Account provisioning

Controls: AC-01, AC-02

Access to production systems is granted through a ticket approved by the line manager. Privileged group membership is reviewed every quarter by the Security team.

## 2. Authentication

Controls: AC-03

All staff accounts use multi-factor authentication. Shared accounts are not permitted.

## 3. Remote access

Controls: AC-09

Remote access to the corporate network uses the managed VPN client only.
