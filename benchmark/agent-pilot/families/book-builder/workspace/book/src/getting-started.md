# Getting started

Tidepool needs a collector address and at least one log path. The shortest path is:

1. Follow the [installation steps](guide/install.md).
2. Create a config file as described in [Configuration](guide/config.md).
3. Run the agent as shown in [usage](guide/usage.md#running-the-agent).

```
# comment inside a code block, not a heading
tidepool run
```
