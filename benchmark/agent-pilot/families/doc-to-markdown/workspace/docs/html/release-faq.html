Release FAQ

How often do we ship?

Every second Tuesday. Hotfixes ship as needed after approval from the on-call lead.

Who approves a release?

  1. The feature owner signs off on scope
  2. QA confirms the regression suite is green
  3. The release manager schedules the window

Rollback

Rollbacks use the previous tagged build. See the runbook for the steps.
