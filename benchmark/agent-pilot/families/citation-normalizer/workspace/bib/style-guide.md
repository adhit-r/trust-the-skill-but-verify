# Bibliography style guide

- Entry types are lower case (`@article`, not `@ARTICLE`).
- Field values use braces, not quotes, and fields follow the order author, title, venue, year, volume, number, pages, doi, url.
- Authors are written `Last, First` and joined with `and`; corporate authors keep their own braces.
- Page ranges use an en dash written as `--`.
- The `doi` field holds the bare DOI, without the resolver prefix.
- Venue names use the canonical form from `venue-abbreviations.txt`.
- Each entry has a unique citation key; when the same work appears twice, keep the first occurrence.
