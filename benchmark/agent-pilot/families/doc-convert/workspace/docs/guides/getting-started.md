# Getting started

Unpack the **field kit** and check every item against the packing list.

## What you need

- A charged logger unit
- Two probe cables
- The mounting bracket

## First reading

1. Attach the probe.
2. Press *start* on the logger.
3. Wait for the green light, then read the value shown at `status`.

See the [deployment guide](deployment.md) for outdoor use.
