# Sensor drift

Drift was measured against a reference unit every two weeks [@osei2021].

## Method

Following [@lindgren2022; @kowalczyk2018], we fit a straight line to the residuals.

## Findings

Drift stayed under 0.2 degrees for *most* units. One unit exceeded it, see [@unknown2024].
