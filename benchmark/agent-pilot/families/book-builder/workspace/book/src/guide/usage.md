# Everyday usage

## Running the agent

Run `tidepool run` in the foreground, or install the service unit to run it in the background.

## Checking status

`tidepool status` prints the queue depth. See the [command reference](../reference/cli.md#status) for options.

## Rotating logs

Rotated files are picked up automatically, see [rotation notes](../reference/cli.md#rotation).
